# PawTrip SA Order Fulfilment Checklist

Use this checklist after a customer places an order. Keep supplier details in private ops records only; do not add supplier names, costs or fulfilment notes to public website pages.

## Checklist

- [ ] Confirm payment received
- [ ] Confirm product availability
- [ ] Place supplier order
- [ ] Save supplier order confirmation
- [ ] Update customer
- [ ] Add tracking
- [ ] Mark order fulfilled
- [ ] Handle delays/refunds if needed

## Internal Notes

- Confirm PayFast payment status before processing.
- If Supabase is enabled, update the order status in `/admin/orders`.
- If there is a delay, contact the customer early with clear wording and options.
- Keep all supplier order confirmations in the private operations folder or store admin system.
